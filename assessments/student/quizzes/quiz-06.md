# Quiz 6 — Checkpoint C (Week 6, L12) · Module 3: Malware & Social Engineering

1. A spoofed sender passes domain alignment checks only if the domain publishes a specific DNS policy record. Name that record type. **[1]**

2. Name **two** pretexts a social-engineering email typically uses to bypass skepticism. **[1]**

3. A security team wants to know whether its awareness program is actually changing behavior. Which metric family beats click-rate, and why in one sentence? **[1]**

4. You must prove two samples are (a) *the same file* and (b) *a near-variant of one another*. Name the appropriate technique for each. **[1]**

5. A Windows implant survives reboot twice via two different autostart routes. Name the ATT&CK tactic and give **two** concrete autostart locations you would check. **[1]**

6. During dynamic analysis, the VM has no real internet access but the sample expects a C2 server. What is this configuration called, and which two problems does it solve? **[1]**

7. *(Scenario, 2 marks)* A Word sample arrives named `Invoice_Q3.docm`. List your first **three** static-triage steps in order, before any detonation, and name the isolation control you rely on when you finally detonate it.

8. *(Scenario, 2 marks)* A small hospital's file servers begin encrypting files at 03:00. Give your first three response actions in order, and name the one decision that must *not* be improvised by the responders.

*Scoring: 1 mark per numbered item; recorded as a fraction of 10.*
