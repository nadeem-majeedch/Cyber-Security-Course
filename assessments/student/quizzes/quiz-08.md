# Quiz 8 — Specimen (Week 8) · Pre-Midterm Practice
**Ungraded self-check · 12 marks · ~12 minutes · CLO-1–CLO-4 · Answer key discussed in class; not posted.**
*These practice items do not appear on the midterm itself — they sample the same skills.*

## Part A — Multiple choice (1 mark each)

**1.** A database column is readable by an intern whose role does not need it. Violation:
- A. Integrity
- B. Confidentiality
- C. Availability
- D. Repudiation

**2.** Altering a cookie from `role=user` to `role=admin` before sending it is:
- A. Spoofing
- B. Tampering
- C. Denial of service
- D. Repudiation

**3.** The single control that eliminates classic SQL injection:
- A. A web application firewall
- B. Parameterized queries
- C. Input length limits
- D. HTTPS everywhere

**4.** `SameSite=Strict` primarily mitigates:
- A. XSS
- B. CSRF
- C. SSRF
- D. Clickjacking

**5.** The safest first artifact to extract from a suspicious document, before any execution:
- A. Network traffic it generates
- B. The embedded macro source (static extraction)
- C. Registry hives
- D. Screenshots of the VM

**6.** A ruleset lacking an explicit final rule relies on:
- A. Implicit default-allow on many platforms — dangerous; write an explicit default-deny
- B. Implicit default-deny with logging
- C. Automatic rule repair
- D. Stateful return-traffic handling

**7.** Backups are classified as which control pair?
- A. Preventive / technical
- B. Corrective / technical
- C. Detective / administrative
- D. Deterrent / physical

## Part B — Short answer (5 marks)

**8.** (a) Why does output encoding fail to prevent command injection? (2)
(b) One reason a malware sample's first execution should happen without internet access? (1)
(c) A rule allows 443 from *any* source to the web tier. Name the residual risk and one narrowing change. (2)
