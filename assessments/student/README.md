# Assessments — Student tier

Task statements, weekly quizzes, specimen papers, project briefs, and rubric summaries shown to students.

**Never place answer keys, exam versions, or grading data here** — those belong in the instructor-only tier, outside this directory tree.

## Weekly quizzes (ungraded, diagnostic)

| Quiz | Week | Format | Paper |
|---|---|---|---|
| Q1 | 1 | Specimen MCQs + short answers | `quizzes/quiz-01.md` |
| Q2 | 2 | Checkpoint A (L04) | `quizzes/quiz-02.md` |
| Q3 | 3 | Specimen | `quizzes/quiz-03.md` |
| Q4 | 4 | Checkpoint B (L08) | `quizzes/quiz-04.md` |
| Q5 | 5 | Specimen | `quizzes/quiz-05.md` |
| Q6 | 6 | Checkpoint C (L12) | `quizzes/quiz-06.md` |
| Q7 | 7 | Specimen | `quizzes/quiz-07.md` |
| Q8 | 8 | Pre-midterm MCQs (midterm is Week 8's assessment unit) | `quizzes/quiz-08.md` |
| Q9 | 9 | Specimen | `quizzes/quiz-09.md` |
| Q10 | 10 | Checkpoint D (L20) | `quizzes/quiz-10.md` |
| Q11 | 11 | Specimen | `quizzes/quiz-11.md` |
| Q12 | 12 | Checkpoint E (L24) | `quizzes/quiz-12.md` |
| Q13 | 13 | Specimen | `quizzes/quiz-13.md` |
| Q14 | 14 | Checkpoint F (L28) | `quizzes/quiz-14.md` |
| Q15 | 15 | Pre-final specimen | `quizzes/quiz-15.md` |
| Q16 | 16 | Midterm/Final assessment unit (graded) | see `specimen-midterm.md`, `specimen-final.md` |

Checkpoints A–F are the graded formative component (15%, lowest dropped); specimen quizzes are ungraded self-checks. Specimen papers draw from the instructor question bank — answer keys are never posted here.

## Files in this directory

- `quizzes/quiz-01.md` … `quiz-15.md` — weekly quiz papers (questions only).
- `practical-assessments.md` — lab grading scheme and report template.
- `short-assignments.md` — assignment briefs (SA-1 … SA-6).
- `case-study-activity.md` — case-brief assessment task and rubric summary.
- `capstone-brief.md` — capstone project instructions.
- `oral-defense-rubric.md` — presentation/defense rubric.
- `specimen-midterm.md`, `specimen-final.md` — practice papers (different items from the live exams).
