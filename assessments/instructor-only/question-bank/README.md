## Item standards (all items comply)

1. **Validated answer + explanation.** Every MCQ key has a one-to-three-sentence rationale; plausible distractors encode real misconceptions.
2. **Bloom level** on every item (Understand → Create, module-appropriate).
3. **CLO mapping** on every item; coverage matrix below.
4. **Difficulty tags** (Easy/Medium/Hard/Expert) for progressive assembly.
5. **No ambiguity rule:** one defensible key; "select best answer" wording where judgment is required; the two deliberately double-defensible items (SF-3, FE-H) say so in the key.
6. **SA mark schemes:** per-mark allocation stated; partial-credit guidance in keys.

## Duplicate-avoidance rule (standing)

- No item appears in more than one live artifact (quiz, midterm, final). Specimen pools (SM/SF) are contaminated for live use the moment they are shown.
- Reusing a semester: draw makeup items from the MT/FE banks' unused items or draft new per the standards above; **never reissue a shown item as graded**.
- Makeup packs MT-1…MT-9 are pre-designated in the QB-M files ("makeup MT-n only") — one per week with quizzes.
