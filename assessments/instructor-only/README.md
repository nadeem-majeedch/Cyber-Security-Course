# ⚠️ INSTRUCTOR-ONLY — Assessments

This tier holds answer keys, quiz/exam versions, grading rubrics, and item analysis.

Access rules:
- Not linked from `website/` and not distributed to students.
- Because this repository is **public**, these files will be readable by anyone — see the open decision in `docs-meta/architecture-and-requirements.md` §11. If the course runs from this repo, move this tier to a private repo or private drive before term start.

## Contents

| File | Purpose |
|---|---|
| `question-bank/QB-M1.md` … `QB-M8.md` | 80 banked items (10 per module: 8 MCQ + 2 short-answer) with keys, Bloom levels, CLO and difficulty tags |
| `question-bank/QB-MT.md`, `QB-FE.md` | Midterm and final bank items (scenario/analytical) with keys and marking schemes |
| `question-bank/QB-SM.md`, `QB-SF.md` | Specimen pools for pre-exam practice quizzes |
| `question-bank/README.md` | Bank map: item → quiz/week/CLO/Bloom/difficulty; duplicate-avoidance rule |
| `checkpoint-keys.md` | Checkpoint A–F keys (= weekly quizzes 2/4/6/10/12/14) |
| `lab-keys.md` | Lab assessment keys and rubric ledger |
| `capstone-rubric.md` | Full 100-mark capstone rubric + moderation guide |
| `midterm-paper.md` | Live midterm paper + marking scheme (A/B variants) |
| `final-paper.md` | Live final paper + marking scheme (A/B variants) |

Student-facing quiz papers live in `../student/quizzes/` (questions only). The weekly quiz map: Q2/4/6/10/12/14 = Checkpoints A–F (keys in `checkpoint-keys.md`); Q1/3/5/7/9/11/13/15 = specimen quizzes drawn from the bank; Q8 = pre-midterm MCQs; Q16 = the graded exam unit (midterm or final week).
