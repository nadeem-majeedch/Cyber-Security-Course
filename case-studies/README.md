# Case Studies (student-facing)

**100 progressive problem-solving cases** (Levels 1–4) used in-class with the course's discussion method:

1. Case on projector → 2. ~5 minutes to propose a solution in groups → 3. groups explain reasoning → 4. facilitated discussion → 5. **model solution revealed** → 6. tradeoffs, assumptions, limitations.

Model solutions, expected reasoning, alternatives, tradeoffs, common mistakes, and instructor discussion prompts live in the **instructor-only** tier (`instructor-materials/instructor-only/case-solutions/`) and are revealed only at step 5.

## Integrity rules

- Every case is a **simulated scenario** written for teaching; organizations, people, hosts, and data are fictional. No case cites a fictional incident as real; external facts referenced in solutions cite public sources only.
- Evidence given in a case is the evidence you may reason from — inventing extra "facts" is a common-mistake pattern the instructor will name.
- Multiple defensible solutions exist for most Level 3–4 cases; grading rewards argued reasoning and named tradeoffs, not a single "right" answer.
